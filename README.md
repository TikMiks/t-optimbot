# Промо-бот t-optim.cc

Телеграм-бот для партнёрской программы: считает покупки настройки ПК по промокодам
и показывает владельцу промокода его продажи, начисления и историю выплат.

- **Администратор** отмечает кнопкой выплату; покупки с сайта сам подтягивает
  из кабинета Platega. Ручная отметка продажи остаётся как запасной вариант.
- **Владелец промокода** получает уведомление о покупке («+500 ₽»), а по кнопке
  «🔄 Обновить статистику» видит актуальные цифры и дату последней выплаты.
- Начисление фиксированное за продажу: 500 ₽ по умолчанию, для каждого промокода
  можно задать своё значение.

## Быстрый старт

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt
copy .env.example .env          # Windows (cp на Linux/macOS)
```

Заполните `.env`:

| Переменная        | Значение                                                        |
| ----------------- | --------------------------------------------------------------- |
| `BOT_TOKEN`       | токен от [@BotFather](https://t.me/BotFather)                   |
| `ADMIN_IDS`       | ваши Telegram ID через запятую (узнать — команда `/id` в боте)   |
| `DEFAULT_REWARD`  | начисление за покупку по умолчанию, в рублях (500)               |
| `DB_PATH`         | путь к файлу базы, по умолчанию `data/bot.db`                    |
| `DATABASE_URL`    | строка подключения Postgres; если задана, `DB_PATH` не нужен     |
| `TZ_OFFSET_HOURS` | часовой пояс для отображения дат (Москва — 3)                    |
| `PLATEGA_MERCHANT_ID` | UUID мерчанта из my.platega.io → Настройки                   |
| `PLATEGA_SECRET`  | API-ключ из того же раздела (не коммитьте)                       |

Запуск:

```bash
python main.py
```

## Как пользоваться

### Подключение нового партнёра

1. В боте: **➕ Новый промокод** → ввести код → указать ставку (или оставить 500 ₽).
2. Бот выдаст одноразовую ссылку вида `https://t.me/ваш_бот?start=b_xxxx`.
3. Отправьте ссылку партнёру. Он переходит по ней — промокод привязан к его аккаунту,
   и он сразу видит свой кабинет.

Если ссылка потерялась — кнопка **🔗 Ссылка для владельца** в карточке промокода
или команда `/link КОД` выдаст новую (старая перестанет работать).

### Покупка по промокоду

Бот раз в минуту забирает выгрузку транзакций из Platega. Успешный платёж
(`CONFIRMED`) с промокодом в `payload` или описании сам попадает в статистику,
владельцу уходит «+500 ₽». Возврат (`CHARGEBACKED`) автоматически списывает
начисление.

Если промокод в платеже не распознан — админу придёт «неразобранный» платёж,
его можно привязать кнопкой.

Запасной ручной путь: **🧾 Отметить продажу** или `/sale NEON15 4500`.

Быстрый способ: `/sale NEON15` или `/sale NEON15 4500`.

Ошиблись — кнопка **↩️ Отменить эту продажу** удалит последнюю запись
и уведомит владельца о списании.

### Выплата партнёру

**💸 Отметить выплату** → выбрать промокод → «✅ Выплатил всё — N ₽» либо ввести
частичную сумму. Остаток к выплате пересчитается, владелец получит уведомление,
а дата и сумма попадут в его блок «Последняя выплата».

Быстрый способ: `/payout NEON15` (весь остаток) или `/payout NEON15 1500`.

### Команды администратора

| Команда                   | Действие                                        |
| ------------------------- | ----------------------------------------------- |
| `/menu`                   | панель управления                               |
| `/sale КОД [сумма]`       | отметить покупку                                |
| `/payout КОД [сумма]`     | отметить выплату (без суммы — весь остаток)     |
| `/addpromo КОД [ставка]`  | создать промокод                                |
| `/rate КОД ставка`        | изменить начисление за покупку                  |
| `/promos`                 | список промокодов                                |
| `/stats`                  | общая статистика и топ промокодов               |
| `/link КОД`               | ссылка привязки владельца                        |
| `/sync`                   | сразу подтянуть оплаты из Platega                |
| `/cancel`                 | прервать текущее действие                        |

## Хостинг на Render (бесплатно)

На бесплатном Render файлы стираются при каждом перезапуске, поэтому база живёт
в бесплатном Postgres на [Supabase](https://supabase.com), а бот работает как
веб-сервис: отвечает на `/health` и сам пингует себя раз в 10 минут, чтобы
Render его не усыплял.

1. Supabase → New project. Затем **Connect** → **Session pooler** → скопировать
   строку `postgresql://...` и подставить в неё пароль базы.
2. Вписать эту строку в `.env` как `DATABASE_URL=...` и перенести данные:
   `python -m scripts.migrate_to_postgres`.
3. Render → **New** → **Blueprint** → выбрать этот репозиторий (`render.yaml`
   уже в нём). Ввести секреты: `BOT_TOKEN`, `DATABASE_URL`,
   `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`.
4. Бот должен работать только в одном месте: локальный запуск при этом
   останавливайте, иначе Telegram выдаст конфликт.

## Данные и бэкап

Без `DATABASE_URL` вся информация лежит в одном файле SQLite (`data/bot.db`).
Для бэкапа достаточно скопировать его вместе с `data/bot.db-wal`, остановив бота.
С Postgres бэкапы делаются в панели Supabase.

Денежные суммы хранятся в копейках целым числом — округлений не возникает.

## Заметки по эксплуатации

- Промокод можно **⏸ выключить** — история сохранится, но код будет помечен как
  неактивный. Удаление (**🗑**) необратимо и уносит продажи с выплатами.
- Если владелец заблокировал бота, админ увидит предупреждение «Не удалось
  доставить уведомление» — запись в статистике при этом создаётся.
- Состояния диалогов хранятся в памяти: после перезапуска незаконченный ввод
  сбрасывается, данные о продажах и выплатах не теряются.
